Global Navbar System

A reusable, responsive, enterprise-grade navigation system built using Web Components.

Features

Centralized Updates

Update once and every app gets the latest navbar instantly.

Responsive

Works across desktop, tablet, and mobile devices.

Easy Integration

One script and one component.

Customizable

Themes, logos, colors, links and layouts.

Quick Start 

<link
rel="stylesheet"
href="https://cdn.minionsenterprises.com/styles/main.css"
/>

<company-navbar></company-navbar>

<script>
window.CompanyNavbarConfig = {

  companyName: "MEQETA",

  subheading:
    "Enterprise Solutions",

  theme: "dark",

  links: [
    {
      label: "Home",
      href: "#",
      icon: "fas fa-home"
    }
  ]
};
</script>

<script type="module">
  import
  "https://cdn.minionsenterprises.com/scripts/main.js";
</script>
